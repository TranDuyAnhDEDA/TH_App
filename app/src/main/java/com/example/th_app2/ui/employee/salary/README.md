# PHẦN VIỆC CỦA THÀNH VIÊN 3: BẢNG LƯƠNG CÁ NHÂN (EMPLOYEE)
- Hiển thị bảng lương chi tiết của nhân viên đang đăng nhập theo từng tháng.
- Thống kê chi tiết:
  + Tổng số giờ làm việc (totalHours).
  + Số giờ làm thêm (overtimeHours).
  + Mức lương theo giờ (hourlyRate).
  + Tổng tiền lương thực nhận (totalSalary).
